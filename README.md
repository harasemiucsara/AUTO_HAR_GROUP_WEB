Auto Har Web este o aplicație web full-stack pentru un magazin online de piese auto second-hand din dezmembrări, 
sub brandul Auto Har Group (Suceava). Oferă un catalog de produse cu filtrare și căutare, coș de cumpărături, 
plasare comenzi cu scădere automată a stocului, și un panou de administrare simplu pentru gestionarea produselor 
și comenzilor.

Backend-ul este scris în Python cu Flask și expune un API REST, iar datele sunt persistate în SQLite. Frontend-ul 
este HTML/CSS/JS static, cu un design dark (roșu + accent mint) inspirat din estetica site-ului de producție 
pieseautohar.ro.
